# EV Digital Dashboard for the Thunderstruck MCU

Files to support my electric vehicle digital dashboard when using the Thunderstruck MCU

## Instructions

1. Install [Car Scanner ELM](https://play.google.com/store/apps/details?id=com.ovz.carscanner) on your Android device. I recommend purchaseing the "pro" tier which is very inexpensive.

2. After initial setup of configuring your car make/profile and your bluetooth ELM device, go to Settings > Sensors > User create (custom) sensors. Click Import and select the "Car Scanner ELM Sensors.csp" file. This should load all of the custom Thunderstuck PIDs into your sensor list.

3. Go to Settings > Dashboard. Click "Restore Dashboard". Pick the appropriate "Car Scanner ELM Dash\*.json" file that is the closest match to your phone screen.
